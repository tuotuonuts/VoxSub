# 模型广场搜索验收

## 实现

- 即时本地搜索名称、模型 ID、语言标签、普通用户标签、描述和用途；提供「全部内容 / 仅名称 / 仅标签」范围选择。
- 中英文索引同时可用；大小写、全角、重音符、标点/空格归一化。英文/数字单词支持轻微拼写错误和相邻字母交换；短词、中文保持字面包含匹配，避免过度误匹配。没有拼音索引或在线搜索。
- 空格分隔的关键词必须同时匹配，可跨字段；引号保留短语。相关性排序优先名称，其次标签和描述；同分保持目录顺序，空查询不排序。
- 用途、只看已下载与搜索取交集，展示结果数。空结果提供重置，重置不改变海外/中国大陆下载源。
- 清空按钮、Escape、中文输入法组合事件支持；输入时只重绘结果网格，不重建或自动聚焦输入框。刷新/重新开页保留本次运行内筛选；查询不写用户配置或日志，不增加搜索 IPC/请求。
- 搜索纯算法在 `frontend/src/shared/model-search.ts`；公共 `SearchField`、`EmptyState` 无 store/IPC/业务依赖，复用已有输入和按钮。
- 同时修复直接相关的用途筛选引用：每次替换筛选条后更新 DOM 引用，反复切换与重置保持可见激活状态；陈旧页面事件和 dispose 不影响新页。
