# 全局快捷键验收

## 功能

入口：设置 → 快捷键。7 个动作默认全部留空，不注册任何组合键：

1. 显示 / 隐藏主窗（关闭主窗后仍在运行时可重建主窗）。
2. 开始 / 结束当前会话。
3. 暂停 / 继续当前会话（A/B 支持；其他模式明确提示不支持）。
4. 结束当前会话。
5. 切换同时录音（遵循后端 recordingSupported/recordingCanChange，不自动启动采集）。
6. 显示 / 隐藏字幕浮窗。
7. 切换浮窗鼠标穿透。

用户可录入按键或手动输入组合键；保存后立即生效，清空并保存后停用。当前支持 Ctrl/Alt/Shift 组合、字母数字、F1–F24、空格/方向等列举键；至少包含 Ctrl 或 Alt，不接受仅普通键、仅修饰键或 Windows 键组合。录入阶段暂时挂起已注册全局快捷键，避免录入时误执行；Esc、失焦、最小化、关页、重载/销毁均释放录入状态。恢复失败显示真实未生效状态。

## 冲突与保存语义

- 规范化 Control/Ctrl、大小写、空格及修饰键顺序后检查重复；两项都显示对应冲突动作。
- 拒绝已知系统保留组合；进一步通过真实全局注册结果检查系统占用或系统拒绝。不能识别占用方软件名称，也不能可靠检测其他软件仅在窗口内使用的快捷键，UI/中英文 README 已说明，不称“全系统所有快捷键冲突均可检测”。
- 修改后自动检查，保存时重新检查；探测不写入设置、不替换已有注册。
- 先获取新增键，再原子写入设置，成功后才释放旧键。注册或写入失败撤销新增键，旧设置和注册保留；互换已拥有的键无需先释放旧键。
- 设置仅写 app userData 中独立 `global-shortcuts.json`（version/bindings），不改后端配置、历史或正文。空默认不创建文件。重启重新注册并报告占用；损坏/过大/无法读取的文件提示错误，不擅自覆盖。
- 退出只注销本模块拥有的键，不调用全局 unregisterAll 影响其他模块。

## 结构与边界

- `shared/shortcuts.ts`：动作/类型、空默认、组合键规范化及纯校验。
- `main/shortcut-manager.ts`：唯一注册 owner、事务式检查/保存、录入 token 和注销。
- `main/shortcut-actions.ts`：直接从主进程查询后端任务与当前状态后发命令，不依赖 renderer 焦点、可见性或乐观状态。会话任务/未确认状态不重复提交；请求受理不冒称推理成功。
- `main/shortcuts.ts`：小型独立偏好文件与服务组装。
- `renderer/ui/shortcut-field.ts`：新增公共可复用字段，组合现有 Field/Input/Button；注册挂起/恢复由调用方注入，不直接调用 IPC 或保存配置，处理取消、异步失效及监听生命周期。
- `renderer/views/shortcuts.ts`：显式保存、自动冲突检查、中文/英文提示、丢弃草稿和清空全部。
- 专用 IPC 只允许当前主窗配置快捷键；浮窗/其他 sender 不得设置。主窗重建和旧窗回调有 owner 检查。

## 未验证 / 验收限制

- 真实最小化/可见托盘窗口的交互 NOT_RUN（避免抢屏）；其行为由真实 main 模块配模拟原生窗口验证。真实 OS 全局注册及隐藏/非聚焦触发已验。
- 真实音频采集、模型加载/推理、C 文件处理、真实会话启停及录音落盘 NOT_RUN；路由、状态和能力保护由隔离单元测试验证，不占用用户音频。
- 非本机键盘布局、AltGr/特殊厂商键、安装包、安装版及跨操作系统 NOT_RUN。没有伪称注册能找出占用方或所有软件本地快捷键。
- HEADLESS 模式下显示主窗/浮窗动作刻意不显示窗口；所有正式全局快捷键仍在主进程注册，音频动作不用于静默验收。
