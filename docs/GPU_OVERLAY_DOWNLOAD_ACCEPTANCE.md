# GPU 模型、悬浮窗裁剪与下载链接防护验收

源码候选版本：0.9.0-beta；本报告对应本轮提交，不表示安装版或可见桌面已验收。

## 交付范围

- Granite 4.0 1B Speech、Index-Echo S2TT 2B：单模型文件字幕可选自动 / CPU / NVIDIA CUDA，以及双语 / 仅译文。共用既有公共表单、选择框、按钮，不另造页面私有控件。
- Granite 按官方模型卡开放 en→zh/fr/de/es/pt/ja/it、fr/de/es/pt/ja→en。双语两次生成，只有译文时一次生成。
- Index 保留官方 BF16 适配器、句子时间戳和双语内部上下文；仅译文不把源文展示或写入字幕，但保留模型内部上下文。官方建议约 10GB 显存并留余量，不保证 8GB 显卡能处理任意音频。
- SeamlessStreaming：新增固定版本权重下载及官方指南。官方依赖 Windows 原生不受支持，因此明确为 Linux/WSL **外部运行、下载入口**；不允许通过配置或使用按钮启动尚未实现的 Windows 推理。CC-BY-NC-4.0，非商业用途；不自动安装或启动 WSL。
- 三款模型均有 Hugging Face 全球与 HF Mirror 大陆镜像、固定文件大小/SHA256和已有断点续传机制。第三方镜像不保证所有网络可达。

这不是新增实时音频 GPU 同传路径。单模型仍限文件模式，独立进程中按官方实现调用，不启动第二套翻译模型。自动选择 CUDA 不可用时记录 CPU 回退；明确选择 CUDA 失败或显存不足时不偷偷改成 CPU。启动不自动装依赖，不改用户已有 ASR/MT、录音及语言配置。

## 根因与修复

### 下载 CI

原先 prepare/snapshot 统计进度直接拼接 `.part` 路径，且缓存会话直接返回，未先调用已有的受限路径校验。现在读取缓存前统一检查最终文件、分片、续传元数据及状态文件；进度统计也经受限路径校验，发现符号链接/重解析越界立即拒绝，不触碰目标文件。

保留用户报告的原失败测试；新增 final/part/resume × 单文件/多文件 × 缓存/无缓存矩阵及不依赖符号链接权限的故障注入测试。没有删除原断言或放宽校验。

### 悬浮窗

同源页面缩放会共享，旧的 `zoom-changed` 监听无法覆盖程序设置缩放和兄弟页面缩放；硬编码区域可能与真实 CSS 卡片错位。另外原生材质 API 不抛错不等于实际成功。

- 悬浮窗 `setZoomMode("isolated")`，初始倍率 1，不修改主窗缩放。
- ResizeObserver、window/visualViewport resize 合并到动画帧，上报实际卡片范围/圆角/视口；仅接受当前悬浮窗的 IPC。
- 共享几何将 CSS 范围转换到 Electron DIP；show、resize、move 和实际框变更刷新。
- 主进程按窗口 owner 和代次隔离，读取 GDI region 和 DWM backdrop。检查失败去除毛玻璃并保留裁剪；清除也无法确认时，先创建普通半透明替代窗再销毁旧窗，避免误触发全窗口关闭。保留隐藏、位置、穿透与显示设置，不抢焦点。
- 修复 preload resize 通道与主进程不一致的问题。
- 日志及开发者快照分别含 `clippingCheck`、`materialCheck`、`desktopCheck`。`desktopCheck` 始终为 `not_run`，除非另有人工可见桌面验收，绝不因原生读回通过就宣称观感通过。日志不含 HWND、字幕正文或音频。

## 验证

验证证据位于仓库外 `D:\OneDrive\app_dve\gpu-overlay-ci-evidence`，未提交环境、权重、音频或用户 Cache。

- Python 全量安全集：1370 passed / 20 skipped / 7 deselected / 1 既有 xfailed，98.09 秒；排除真实硬件发声/录音项。独立 APPDATA/LOCALAPPDATA 和 pytest basetemp。
- 前端 `npm run check`、构建、发布 `--check-only`；不执行安装包发布。
- 新的控制器/几何/观察器回归 8 项；窗口生命周期 52 项；模型公共 UI 12 项；模型卡 21 项。覆盖迟到结果、关闭/重建、失败回退、隐藏状态、外部模型不可选择、GPU/output 配置即时应用。
- 真实隐藏 Electron HWND：10 组原生裁剪及材质读回通过；同源兄弟页面 150% 缩放不影响悬浮窗；自身 100/125/150/200% 及三种尺寸通过；测试窗显示/聚焦违规 0。仅测本机报告的 DPI，不是所有物理 DPI 验收。
- RTX 4060：PyTorch 2.11.0+cu128 / CUDA 12.8 / BF16 可用，实际 CUDA 张量计算通过。Granite 用已有隔离测试音频做英语→中文、仅译文真实调用，收到 CUDA 推理完成事件，原文输出为空且译文非空；单次冷启动总耗时约 31.74 秒，其中分段生成约 2.75 秒。包含文件校验/加载成本，非实时性能承诺、非质量基准，不能与不同输出模式的旧 CPU 数字直接比较。
- SeamlessStreaming 两种源各 5 个文件 HEAD 均 200，远端长度与固定清单一致；未为本次验收下载全部约 8GB 权重，也未运行 Linux/WSL 推理。

## 未验证 / 限制

- 可见桌面 DWM 观感、真实截图/录屏、跨物理 DPI、用户当前运行实例、打包安装版：NOT_RUN。未重启用户应用，未播放音频或录音。
- Index 本轮没有做 RTX 4060 真实推理/显存容量验收；保留上一轮 CPU 文件推理证据，但不据此声称 GPU 质量/速度通过。
- Windows 本机没有创建符号链接权限，13 个真实文件链接案例跳过；无权限故障注入与其余下载回归通过。远端 CI 创建链接的原案例仍保留，最终以远端执行结果为准。
- 云端 GitHub Actions 状态不由本地测试推定。提交及推送成功不等于远端流水线已通过。
