# 主页语言搜索选择验收

日期：2026-10-05 UTC

## 交付

识别语言与目标语言统一使用公共 `ui/searchable-select.ts`。保留展开列表选择，同时允许输入中文名、英文名或语言代码进行大小写不敏感的子串/多关键词匹配，兼容重音字符。别名只用于搜索，不扩充模型能力范围。

输入不触发 IPC 或保存；点击候选、方向键＋Enter 才提交，Esc、Tab、失焦、点击外部取消临时搜索并恢复已选值。输入法确认不误当成选项确认。没有结果时提示，不把自由文本当语言值保存。

语言 owner 继续读取后端方向矩阵，并维护确认中、断连、加载时语言锁定、文件任务运行锁定、模型变更及过期回执保护。字幕/日志更新不重建候选、抢输入焦点或覆盖正在输入的文本。缓存标签/别名，避免每个字幕事件重新创建大量语言显示对象。

控件复用公共输入框和按钮；弹出层使用 Chromium top layer，按视口定位、可滚动，避免被侧栏裁切。关闭及 dispose 移除临时全局监听。周围页面滚动时关闭菜单，避免弹出框脱离输入框。

- `npm run check` 与生产构建。
