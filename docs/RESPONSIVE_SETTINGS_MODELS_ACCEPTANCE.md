# 分辨率适配与设置模型刷新验收（2026-10-05）

版本：0.9.0-beta 源码；基线 f90bdd3；时区 Asia/Singapore。用户已确认修复方向。

## 根因与修复

- SenseVoice 权重和词表存在且哈希在诊断阶段核对通过；后端判断已安装。设置只在 `loadConfig` 中取模型清单，启动取过配置后重开设置不再查询，导致下载之后仍使用旧列表。改为每次打开设置独立刷新模型清单，接受的下载完成事件及成功的安装/卸载/导入请求会通知刷新。
- 识别、翻译、朗读选项共用独立 SettingsModelCatalog；仅原位更新模型控件，不重新读取整份配置或重建页面。请求代次与页面 owner 共同防止迟到结果覆盖新页；dispose 清理监听和字段引用，旧导航/重试按钮不污染当前页。
- 配置里的模型缺失时显示明确占位，而不是假装选中了列表第一个模型；不自动写配置。读取失败保留缓存但禁用选择，并展示读取失败及重试；空清单与失败分开。
- 通用选项更新收编为公共 `ui/select-options.ts`，已有公共 Select 也使用它；模型字段复用 Field/Button/Select，不复制页面私有控件。更新不替换 select、不触发 change，标签按纯文本处理；中文/English 文案同步。
- 主窗原固定最小 1000×660，不适合小工作区与高缩放。初始窗口按鼠标所在显示器的 workArea（Electron DIP）居中并限制尺寸；足够大时仍为 1240×820，最小尺寸不大于该工作区，不重复乘 DPI。
- 窄窗/低高度下设置与诊断导航横排换行；主屏窄窗模式按钮横排，模型卡自动减列；控件、长字段、路径、日志和诊断行重排/换行。低高度主屏允许整页滚动，保留字幕独立滚动；OCR 窄窗改单列。没有用全局缩小字号替代布局。
- 返回栏与宽窗 sticky 导航避让原生标题按钮和可拖拽条；滚动到底后返回按钮不会被标题区域覆盖。小窗口仍可返回，不要求先滚回顶部。
