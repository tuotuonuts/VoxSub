# 模型下载断点续传验收

日期：2026-10-05。范围：模型广场的下载会话、HTTP 续传、IPC 与卡片控件；源码版本由仓库外 DELIVERY.json 记录。

## 用户操作

- 下载中显示「暂停」；发送暂停后短暂显示「正在暂停」，只有写入线程确实停止后才显示「继续 / 删除」。
- 暂停保留进度和暂存文件；继续恢复同一任务，完成后恢复既有「使用 / 卸载」入口。
- 意外退出后重新进入模型广场，磁盘上的未完成会话恢复为暂停；不自动发起网络下载。
- 删除另行确认，只删除该任务的下载和解压暂存，不卸载已安装模型，不删除其他任务。
- 自动 / 海外 / 中国大陆入口保留；重启后继续默认保留原来源偏好，用户显式改来源优先。自动续传优先使用已证明的原源，避免重新探测导致镜像漂移。

## 实现与边界

1. 核心 `voxsub/model_downloads.py` 单独管理根目录级锁、任务 token、单调 revision、取消信号和原子 JSON 会话记录。prepare 在进入串行任务队列前落盘；暂停走即时 IPC，不被下载 worker 阻塞。读取列表只恢复状态，不启动 worker。
2. 下载使用 `.part` 与 `.part.resume.json`，记录 URL 哈希、强 ETag 或 Last-Modified；Range/If-Range 校验偏移和响应长度。源发生变化、服务器忽略 Range 或无法证明同一内容时安全重下；跨源前缀复用必须有最终 SHA256 校验，避免拼接不同权重。服务器不支持安全续传时不能保证省流量，但不会将混合文件作为成功模型。
3. 读取采用可用时的 read1，避免慢链路等待整块数据才响应暂停。网络完全停顿时仍可能等待当前网络读取超时（15 秒）；界面保持「正在暂停」，不提前放开删除。
4. 校验/解压可取消，压缩包拒绝链接和特殊文件；完整解压后同卷原子发布。`.downloads` / `.installing` 和恢复元数据不计入已安装模型完整性清单。根目录别名在运行态规范化，不修改保存的用户配置；内部重定向暂存目录拒绝使用。
5. UI 复用公共 Button、ProgressBar 与确认组件，为公共 ProgressBar 增加暂停态；下载状态 reducer 隔离根目录、淘汰旧 revision、保留终态墓碑，避免迟到的旧请求/进度覆盖继续后的任务。原长请求响应丢失时也通过完成事件刷新安装状态。
6. 元数据大小、字段、revision 范围与资产路径校验；错误会保留断点，损坏会话隔离而不隐藏整个目录。已有 CLI 默认行为保留，安全续传由模型广场显式启用。
