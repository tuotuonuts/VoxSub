# 单模型文件语音翻译验收（2026-10-05 UTC）

## 结论

Granite 4.0 1B Speech 与 Index-Echo S2TT 2B 已接入生产代码及模型广场，**仅用于 C 音视频文件字幕模式**，不作为实时翻译加速方案。源码应用 Pipeline、真实 NDJSON IPC、独立冻结模型组件均已运行；这不同于早期仅在参考脚本中推理成功。

本轮为源码交付及独立组件验收，**没有发布或安装完整 Electron 安装包，也没有重启用户现有实例**。GitHub 是否推送以交付消息为准，本轮未擅自推送。

## 产品适配

- 默认双模型不变，独立持久化 file_translation_mode / speech_model_id；旧配置恢复为双模型。主页文件区和设置使用同一无 IPC 公共表单。
- 单模型路线不建立 ASR＋独立翻译器，先释放已停止的双模型资源；本地/云 ASR、MT、朗读及 OCR 配置保留，切回 A/B/D 不使用该路线。
- Granite 首批开放英→中；Index 开放中→英/日/西。它们是当前已接入验收的方向，不宣称覆盖 Granite 家族所有发布能力。语言控件按方向更新，不提供不安全的自动识别选项。
- 文件处理中禁止更换模型/语言；不采集、保存录音或播放语音。下载与模型选项错误有可见状态和重试；不静默换模型、不自动转云。
- 模型广场增加语音翻译分类、可搜索标签、固定版本双源文件清单及持久化选中状态。Index 使用官方 GitHub 图标入口；Granite 使用已确认的官方 Hugging Face 入口。
- Granite 同一权重顺序生成原文、译文两次；使用分段时间范围，不伪装精确逐句/逐词对齐。Index 严格检查输出完整性、时序、范围与重叠。
- 有界 PCM 分窗（至多 15 秒，尽量靠近静音边界，不删除帧）；Index 只保留前两窗、每窗最多 2000 字符的上下文。真实重复句在不同媒体时间不能去重。
- 字幕事件携带可选 startMs/endMs，自动及手动导出保留媒体时间而非推理墙钟时间；兼容旧实时事件。自动写入新的 `.voxsub.srt`，不覆盖已有文件。

## 运行与资源所有权

隔离 `.venv-speech`／`VoxSubSpeechWorker`；CPU BF16，2 线程，低优先级。源码环境使用 requirements-speech.lock；发布构建必须生成并带上独立 worker。模型权重不随安装包分发。

文件加载前逐文件检查大小和 SHA256，运行时离线加载，不执行权重目录内的 Python，不启用 trust_remote_code。启动可用内存门槛 Granite 8 GiB、Index 10 GiB，运行期间不足 1 GiB 停止本任务；这不是总内存或所有设备适配保证。

worker 与 ffmpeg 均关闭交互 stdin、隐藏启动、由 Windows kill-on-close Job 管理。停止与后台异常退出只清理本任务子进程。无消息超时为 600 秒；超时、内存不足、空/截断/非法输出、异常退出不导出伪成功文件。

诊断保存加载阶段、实际组件/设备事件、段耗时、错误类型和不含路径的代码位置；失败、取消不再被 file_session 装饰器记成完成。释放后不声称仍在推理。日志元数据不含音频或识别/翻译正文。

## 已验证

详见 `SINGLE_MODEL_SPEECH_EVIDENCE.json`，时间戳统一为 UTC。外部证据目录名称采用运行主机的 UTC+08 日历标签。

- 源码生产 Pipeline：Granite 英→中，Index 中→英／日／西，真实固定权重、已知合成短句，全部生成可导出的双语字幕。人工核对参考文字保留主要含义与数字；未播放音频，没有统计准确率结论。
- 冻结独立组件：Granite 双语生成；Index 约 19.52 秒、跨两窗的合成文件，两个句子正确映射到全局时间范围并保留第二窗上下文。源码与冻结组件均不加载独立 MT。
- 实际 NDJSON IPC：模型目录／选中状态、能力矩阵、启动、定稿时间戳事件、完成导出、idle 与 shutdown＋stdin EOF 收尾通过。
- 真实 MP4 转换为 16kHz/单声道/PCM16，未调用播放器。真实冻结 Granite 加载后取消约 0.047 秒返回，没有遗留子进程；该数值不是每台机器的取消时延保证。
- Windows 异常父进程退出的 Job 所有权、闲置输入管道不阻塞 worker 启动，均有真实子进程回归测试。
- 海外/大陆镜像：58/58 文件地址检查通过。小文件完整 SHA256，大权重 HTTP 分段读取与已校验本地权重前缀相符。**没有声称两条线路都完整重新下载了全部 GB 权重**；安装下载仍强制完整文件 SHA256、复用既有断点续传控制器。
- 前端 npm run check 通过；新表单／连接层／导出时间轴 11 项 MiniDOM 用例。离屏真实 Chromium 检查 24 项，157 次窗口状态采样、0 可见或聚焦违规、0 渲染错误。使用实际生产 renderer 与内存后端夹具，不冒称可见桌面验收。
- Python：1347 passed / 8 skipped / 7 hardware_audio deselected / 1 既有 xfailed。新语音翻译用例 24 项；没有放宽架构复杂度或回归门槛。

## 验收中发现并修复

1. 独立环境漏装 Granite 所需 torchaudio：补入固定依赖，并以真实推理复验。
2. 不能把所有 `.txt` 排除出模型资产：统一运行文件筛选，保留 tokenizer merges，排除参考脚本、说明和样本音频。
3. 新控件重复订阅/重读设置：设置复用原目录 owner；workspace 复用既有状态订阅，页面释放、错误/迟到回执回归通过。
4. Windows IPC 父进程读管道期间，继承 stdin 的 Python worker 会停在启动：明确 DEVNULL，新增回归并重新跑通真实 IPC。
5. 验收脚本曾仅发 shutdown 而未像应用一样关闭 stdin：保留失败证据，修正测试收尾为 shutdown＋EOF 后完整复验，未用强退伪装正常退出。

## 验收边界

当前为低线程 CPU 文件路径，短样本包含加载/校验约一分钟以上；不能解决实时播放落后数句话的问题。单模型并不意味着更省内存。未验证 GPU/NPU、长达数小时的原生文件、广泛真实场景质量或 WER/BLEU、各大陆运营商连通性、完整发布安装包。共享语言控件仅展示当前产品开放方向。

全程未播放、未采集用户音频，未操作/重启现有应用，未修改用户配置或历史；模型测试使用隔离目录及旧验收权重的硬链接，不自动迁移到用户模型目录。
